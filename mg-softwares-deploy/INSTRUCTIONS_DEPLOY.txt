🚀 ÉTAPES DE DÉPLOIEMENT (5 minutes)
═════════════════════════════════════════════════════════════════════════════

1️⃣  EXTRAIRE LE ZIP
    └─ Extraire le contenu du ZIP dans votre dossier mg-softwares-main

2️⃣  REMPLACER LES FICHIERS
    ├─ index.html           → Remplacer l'ancien par celui-ci
    ├─ 404.html             → Remplacer l'ancien par celui-ci
    ├─ sitemap.xml          → Remplacer l'ancien par celui-ci
    ├─ robots.txt           → Remplacer l'ancien par celui-ci
    └─ ⚠️  NE PAS SUPPRIMER les icônes et autres fichiers

3️⃣  AJOUTER LES NOUVEAUX FICHIERS
    ├─ Créer le dossier: data/ (s'il n'existe pas)
    ├─ Ajouter: app.js (à la racine)
    ├─ Ajouter: data/pages.json (dans le dossier data/)
    └─ Ajouter: Documentation (README.md, QUICK_START.md, etc.)

4️⃣  VÉRIFIER AVEC GIT
    └─ Ouvrir Terminal/PowerShell dans votre dossier
    └─ $ git status
    └─ Vérifier que les fichiers modifiés s'affichent

5️⃣  COMMIT ET PUSH
    └─ $ git add -A
    └─ $ git commit -m "Migration vers SPA avec clean URLs"
    └─ $ git push origin main

6️⃣  ATTENDRE LE DÉPLOIEMENT
    └─ ⏳ 1-2 minutes pour GitHub Pages
    └─ Puis visiter votre site

7️⃣  TESTER EN LIVE

🆘 PROBLÈMES COURANTS
═════════════════════════════════════════════════════════════════════════════

❌ "Chargement..." infini
   → Vérifier data/pages.json existe
   → Vérifier app.js est présent

❌ Site ne charge pas
   → Attendre 2-3 minutes après push
   → Vider cache du navigateur (Ctrl+Shift+R)

❌ Erreurs console
   → Lire DEPLOYMENT.md section Troubleshooting

❌ Fichiers manquants
   → Vérifier que data/ est un dossier (pas un fichier)
   → Vérifier app.js est à la racine (pas dans un sous-dossier)
